## U1 预置凭据登录熔断(v0.4.82,直接移植)

- **源**:`git show 65be1d6 --stat`;上游 `agent/login_breaker.go`(+测试)、
  `sessionLogin` 前置熔断检查与 401/403 结果记账。
- **意图**:密码过期/改密后,多 worker 对同一预置凭据反复 401/403 会锁死客户账号。
  按 `asset_id+auth_index` 维度对预置凭据做 **2 次失败熔断 30 分钟**:熔断期本地直接拒绝
  (不发请求),超时后 half-open 放行一次试探,成功即自愈。
- **落点**:`internal/agent/login_breaker.go`(新,纯 Go 状态机)+
  `internal/agent/tools_http.go:648 sessionLogin` 接线(调用前查熔断、结果后记账)。
- **改写点**:状态存储形态照抄上游(内存 map 即可,单进程单体,无需 db);熔断参数
  (2 次/30min)可先常量,不做 settings 键;仅作用于**预置凭据**,不拦用户手填的
  run 级凭据。
- **测试**:状态机表驱动单测(失败计数→熔断→本地拒绝→half-open→成功自愈/失败续熔)。
