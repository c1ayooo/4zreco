## 安全政策

4zreco 是一个 AI 自主渗透测试平台：可自主执行工具、运行流量记录代理、推进攻击链并留存证据。
**本平台仅供授权测试使用**——请确保每次部署都在书面授权范围内，使用者对所有行为负责。

### 支持版本

本项目不维护长期支持分支。安全修复落在最新主线，建议始终跟随最新 release 或源码树。

### 报告漏洞

请不要在公开 Issue 中提交可被利用的漏洞细节。请使用
[GitHub Security Advisories](https://github.com/c1ayooo/4zreco/security/advisories/new)
私密报告，我们会在 72 小时内确认，并与报告者协同披露。

## Security Policy

4zreco is an AI-driven autonomous penetration testing platform: it executes tools, runs a
traffic-recording proxy, advances attack chains, and keeps evidence. **Authorized testing
only** — make sure every deployment is covered by written authorization; you are responsible
for all actions taken with it.

### Supported Versions

No long-term support branches are maintained. Security fixes land on the latest mainline;
always follow the latest release or source tree.

### Reporting a Vulnerability

Please do not open public issues with exploitable details. Use
[GitHub Security Advisories](https://github.com/c1ayooo/4zreco/security/advisories/new)
for private reports. We acknowledge within 72 hours and coordinate disclosure with you.
